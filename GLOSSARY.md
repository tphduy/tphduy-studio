# Dogfooding skills

How this marketplace's maintainer exercises a skill on real work and learns what to improve in it.

## Language

**Skill under test**:
The skill whose instructions are being exercised and reviewed.
_Avoid_: subject skill, candidate skill

**Target project**:
The project directory in which a trial run executes.
_Avoid_: test project, sandbox

**Trial run**:
One headless execution of the skill under test against a target project.
_Avoid_: test run, dry run, eval

**Retrospective**:
The analysis of a trial run's record that yields findings about the skill under test.
_Avoid_: review, audit, postmortem
